#Cyclistic Bike-Share Analysis (2025)
Project Overview
This project analyzes 12 months of Cyclistic bike-share data to understand how casual riders and annual members use bikes differently. The goal is to identify behavioral patterns and provide data-driven recommendations to help convert casual riders into annual members.
________________________________________
# Business Task
How do annual members and casual riders use Cyclistic bikes differently?
The insights from this analysis will support the marketing team in designing targeted campaigns to increase annual memberships.
________________________________________

# Key Visualizations & Insights
• Weekly Ride Pattern by User Type
Insight: - Members ride consistently on weekdays - Casual riders peak on weekends
Conclusion: Members use bikes for commuting; casual riders use them for leisure.
________________________________________
• Monthly Ride Trends
Insight: - Ride volume peaks during summer (June–August) - Casual riders are highly seasonal
Conclusion: Seasonal promotions can increase casual-to-member conversions.
________________________________________
• Hourly Ride Patterns
Insight: - Members show commute-hour peaks (8–9 AM, 5–6 PM) - Casual riders peak mid-day and evenings
Conclusion: Members use bikes for daily routines; casual riders use bikes flexibly.
________________________________________
• Bike Type Usage
Insight: - Casual riders prefer electric bikes more than members
Conclusion: Electric-bike-focused offers may attract casual users toward memberships.
________________________________________
# Summary of Findings
User Type	Behavior Pattern
Members	Frequent, weekday, commute-based
Casual	Weekend, seasonal, leisure-based
________________________________________
# Business Recommendations
1.	Introduce weekend or flexible memberships
2.	Offer seasonal discounts during summer
3.	Promote memberships near tourist & recreational locations
4.	Target frequent casual riders with long-ride benefits
5.	Use electric bike promotions to drive conversions
________________________________________
# Conclusion
This analysis clearly shows behavioral differences between casual riders and members. By leveraging these insights, Cyclistic can design targeted marketing strategies to increase annual memberships and overall revenue.
